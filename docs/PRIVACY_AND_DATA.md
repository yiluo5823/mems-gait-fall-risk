# 隐私与数据说明

## 数据来源

本仓库不包含真实老年人、患者或受试者数据。压力、IMU和体征数据均由代码按照参数规则生成。

## 个人信息

公开仓库不包含姓名、学号、班级、电话号码、电子邮箱、家庭住址、本机用户名或本机绝对路径。课程报告、答辩文件、申报书和其他可能包含身份信息的材料未纳入仓库。

## 使用建议

如果未来加入真实数据，应在提交到Git之前完成：

1. 获取必要的伦理审批和知情同意。
2. 删除直接身份标识和可关联身份信息。
3. 仅保留研究所需的最小数据字段。
4. 将原始数据放在受控存储中，不直接提交GitHub。
5. 记录数据访问权限、保留期限和删除流程。
